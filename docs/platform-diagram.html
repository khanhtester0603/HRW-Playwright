Kiến trúc Platform regression

Hiện trạng theo mã nguồn ngày 26/11/2026. Platform quản lý bộ test, điều phối Playwright và đối chiếu kết quả giữa các lần chạy.

Kiến trúc Vòng đời lần chạy Điểm sửa mã

Kiến trúc và luồng dữ liệu

  • Khởi động. npm start chạy Node HTTP trên 127.0.0.1, mặc định cổng 4173. Server kiểm tra Host và Origin nếu có. Có nhánh hỗ trợ yêu cầu do Tailnet chuyển tiếp theo cấu hình HRW_TAILSCALE_HOST.
  • Chọn test. Playwright đọc test từ checkout trên máy chạy Platform. Suite lưu tên, mô tả, môi trường và tag. API checklist gọi Playwright với --list để đọc case và annotation; khi thực thi, CLI chọn thư mục theo môi trường và lọc tag nếu có. Mã build là nhãn để tra cứu và so sánh.
  • Lưu dữ liệu. state.json chứa cấu hình suite và lịch sử, gồm bản sao suite và kết quả case theo lần chạy. Thư mục <run-id>/ chứa run.log, results.json và artifacts/ khi có. Đường dẫn gốc mặc định là .platform-data/, có thể đổi qua HRW_DATA_DIR.

Vòng đời lần chạy

  • POST /api/runs lưu lần chạy, gọi bộ điều phối và trả HTTP 202. Một tiến trình chạy test tại một thời điểm; API checklist có thể khởi chạy riêng một tiến trình liệt kê.
  • Trong lúc chờ hoặc đang chạy, trang chi tiết đọc lại API mỗi 800 ms. Reporter đẩy tiến độ qua stdout/stderr; server ghi vào log và đọc JSON khi tiến trình con kết thúc.
  • Điều kiện error được xét trước passed và failed: lỗi cấp báo cáo, thiếu báo cáo/case hoặc exit khác 0 mà không có case unexpected. Khi khởi động lại, lần chạy còn running chuyển sang error và hàng đợi tiếp tục.

Điểm sửa mã

Khi phát triểnVị trí trong repoHành vi hiện tại
Đổi màn hình hoặc điều hướngapp.js · index.html · style.cssrender() điều hướng theo hash; comparison() so khớp ID case ở hai run của cùng suite.
Thay API suite hoặc checklistserver.js · checklist.jsroute() xử lý suite CRUD; suiteValues() kiểm tra dữ liệu; listSuiteCases() đọc annotation checklist.
Đổi hàng đợi hoặc lưu trữserver.jswork(), loadState() và save() quản lý tiến trình con, phục hồi và ghi JSON qua tệp tạm. Xóa lịch sử bị từ chối khi có run đang chờ hoặc đang chạy.
Thêm test hoặc môi trườngtests/production · tests/staging · environments/index.jsProduction chứa HaraWorks và Thư Nội Bộ; staging chứa đăng nhập Zuizui và giỏ hàng mẫu. playwrightArgs() chọn thư mục và lọc tag.
Đổi log, kết quả hoặc artifactreporter.js · playwright.config.js · server.jsReporter tùy chỉnh ghi tiến độ; JSON reporter tạo dữ liệu cho readResults(). API run cung cấp chi tiết, log, JSON và artifact.

Để cập nhật sơ đồ, sửa trực tiếp SVG trong tệp HTML này. Mỗi khối có data-node-id riêng. Khi đổi một khối hoặc trạng thái, cập nhật mũi tên và hàng tham chiếu tương ứng, rồi mở lại tệp để kiểm tra.
